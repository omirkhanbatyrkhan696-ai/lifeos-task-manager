# LifeOS

Веб-жүйе адамға күнделікті тапсырмаларын басқаруға көмектеседі: әр орындалған тапсырма үшін XP беріліп, деңгей өседі, жетістіктер ашылады. Мотивациясы төмен және өз уақытын жоспарлағысы келетін студенттер мен жұмысшыларға арналған.

## Мақсаты
Күнделікті тапсырмаларды ойын механикасы арқылы қызықты етіп, пайдаланушының тұрақты жұмыс істеу әдетін қалыптастыру.

## Пайдаланушылар
- Пайдаланушы (тапсырмаларды орындаушы)
- Әкімші

## Талаптар
1. Пайдаланушы тіркеліп, жүйеге кіреді.
2. Пайдаланушы жаңа тапсырма құрады (атауы, күрделілігі, мерзімі).
3. Пайдаланушы тапсырманы орындалды деп белгілейді.
4. Жүйе орындалған тапсырма үшін күрделілігіне қарай XP есептейді.
5. Жүйе XP жеткілікті болғанда пайдаланушының деңгейін көтереді.
6. Жүйе шарт орындалғанда жетістікті ашады.
7. Пайдаланушы өз профилін, деңгейін және ашылған жетістіктерін көреді.
8. Әкімші жетістіктер мен тапсырма күрделілігінің ережелерін басқарады.
